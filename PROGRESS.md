`git filter-repo`. All 15 spike commits are kept, with the same messages and dates.

**The raw spike data isn't lost:** it's still in the spike repo, and the new bench scripts read
it (see "After review" below).

### `./check`

| Step | What it runs |
|---|---|
| Hygiene | SPDX header on every source file; no file over 1 MiB outside LFS. I checked that both fail on a bad file. |
| Rust | `cargo fmt --check`, `cargo clippy -D warnings` (native, and `drape-web` for wasm32), `cargo test` (13 tests). All with `--locked`. |
| Web | `npm ci` if needed, then `npm run build`: the wasm build, asset export and production bundle. |

| Drapes | **Placeholder** until the M3 golden suite: the three garments at 10k with self-collision, natively. Each must have no NaN and penetration < 2 mm. The T-shirt and trousers must also come to rest with 0 persistent self-intersections. |

### Notes and open items for you

- **`VITRYNE_MVP_PLAN.md` isn't committed.** It's still untracked in the spike folder. Its M8
  section names two CLO patents. Committing that to a public repo puts a written record of
  patent awareness in public, which is worth running past whoever does the freedom-to-operate
  check first. I'd keep the plan private, or commit it without that paragraph.
- **The spike's 15 commits have no `Signed-off-by`.** Every commit from M0 on does.
  CONTRIBUTING.md says the imported history predates the rule. A DCO bot on pull requests only
  checks the PR's own commits, so this won't block anything.
- **Tools installed with Homebrew for M0:** `gitleaks`, `git-filter-repo`, `git-lfs`. I also
  added the `clippy` and `rustfmt` rustup components, which were missing. Note that
  `~/.cargo/bin` isn't on your shell's `PATH` here; `./check` expects `cargo` on the `PATH`.
- **To push:** `git remote add origin <url> && git push -u origin master`. No LFS objects exist
  yet, so the first push doesn't need LFS on the remote.
- **The README's browser support line** says what's tested (Chrome and Safari on an M2). M1
  fills in Firefox and Windows.
- **Unchanged from the spike, on purpose:** crate names (`drape-*`), the plain-JS `web/` viewer
  (until `app/` in M6), and the engine's known weaknesses (fabric stretch is M2).
