A Vitryne instance is the editor's static files, served by one container, plus a
[Supabase](https://supabase.com) project that holds accounts and projects. Supabase's free
plan is enough to start.

## Run the editor

Download the compose file and the example settings from the latest
[release](https://github.com/H4kken/vitryne/releases):

```sh
mkdir vitryne && cd vitryne
curl -fsSLO https://github.com/H4kken/vitryne/releases/latest/download/docker-compose.yml
curl -fsSL https://github.com/H4kken/vitryne/releases/latest/download/env.example -o .env
```

Set `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY` in `.env`, then start it:

```sh
docker compose up -d
```

The editor is at http://localhost:8000.

## Update

Set `VITRYNE_VERSION` in `.env` to the new release, then run `docker compose up -d` again.
